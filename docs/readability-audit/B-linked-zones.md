# Audit B: linked, playable and returning cards (exile, graveyard, command zone)

Read-only audit, 2026-11-12. Code checked: `bridge/bridge.js`, `tools/engine-renderer.lua`, `engine/manabrew.patch`; docs: `reports/MTG linked exile and zone quirks.md`, HAND-TEST-40/HP16, `docs/cost-badge-spec.md`, `docs/status-objects-spec.md`. Prepared is skipped (another agent).
Nothing was run (no TTS, no bridge); "unverified" marks what only a live game can settle.

What the engine sends today (patch lines ~821-835, 1301): `exiledWith` (+ `returnsWhenHostLeaves`, only while the card is in exile), `isForetold`, `isPlotted`, `isWarpExiled`, `isMadnessExiled`, `encodedOn`, `mayPlay` (a yes/no, nothing about source, cost or expiry), counters. It sends NOT: an imprint list, any delayed trigger ("at the beginning of the next end step"), who/what granted a MayPlay, its duration, its cost, unearth/dash/blitz-style flags.
